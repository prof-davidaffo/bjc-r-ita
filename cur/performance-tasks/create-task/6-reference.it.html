Preparare il tuo Personalized Project Reference

In questa pagina, svilupperai un foglio Personalized Project Reference basato sul tuo progetto Snap! da usare nell'esame AP.

Invierai immagini del codice al College Board in due punti diversi:

  • Per il Component A (program code), invierai un'immagine di tutto il codice, inclusi commenti e citazioni.
  • Per il Component C (Personalized Project Reference), invierai immagini di porzioni specifiche del codice, senza commenti.
Durante la parte scritta dell'esame AP potrai usare solo ciò che si trova sul tuo Personalized Project Reference.

  1. Segui le linee guida del College Board per identificare nel progetto due segmenti di codice di procedura e due segmenti di codice di lista. Ecco un riepilogo, ma conferma sempre con i requisiti del College Board:
    1. I due segmenti di codice della procedura devono mostrare:
      1. Una procedura sviluppata dallo studente che mostri nome, eventuale tipo di dato restituito, input e loro uso, e l'algoritmo interno con sequenza, selezione e iterazione.
      2. Una sezione del programma che chiama quella procedura.
    2. I due segmenti di codice della lista devono mostrare:
      1. Una sezione del programma che mostra come i dati sono stati memorizzati in una lista e come si chiama quella lista.
      2. Una sezione del programma che mostra come i dati nella stessa lista sono usati per lo scopo del programma.
  2. Crea il tuo Personalized Project Reference con i quattro segmenti di codice identificati sopra.
    Durante l'esame AP, la scuola fornira' una stampa del tuo Personalized Project Reference. Per la Practice Create Task, se scopri di non poter rispondere ad alcuni prompt della pagina successiva usando solo i quattro segmenti scelti, puoi revisionare il foglio. Nell'esame AP ufficiale non potrai revisionarlo, quindi usa la Practice Create Task per capire quali segmenti conviene includere.

    3. Mostrare il tuo codice

    Snap! offre due modi comodi per ottenere immagini di parte o di tutto il codice:

    • Creare Script Pics

      Puoi scaricare un'immagine PNG di qualunque blocco o script facendo clic destro (o control-clic su Mac) e scegliendo "script pic..." Cerca il file nella cartella Download del browser.

      Se fai shift-clic destro su un blocco reporter, puoi ottenere uno script pic del reporter con il fumetto del risultato visibile.

    • Esportare tutte le immagini insieme

      Puoi scaricare un file HTML con tutti i blocchi del progetto e un'immagine dello stage scegliendo "Export summary..." dal menu File di Snap! (). Aprilo nel browser, fai clic destro per copiare le immagini necessarie e incollale nel documento in cui descrivi il codice.
