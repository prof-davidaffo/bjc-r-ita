Gerarchia degli indirizzi

In questa pagina, impari a interpretare le parti di un nome di dominio e di un indirizzo IP.

Un nome di dominio è un modo leggibile dalle persone per localizzare un sito Internet.

Un indirizzo IP è un modo leggibile dalle macchine per localizzare un sito Internet.

Una gerarchia è un'organizzazione con categorie grandi in alto e sottocategorie sotto.

Il DNS è un protocollo di Internet che traduce nomi di dominio in indirizzi IP.

Su Internet esistono due sistemi di indirizzamento gerarchico: i nomi di dominio e gli indirizzi IP. Le persone usano nomi come snap.berkeley.edu; i computer usano indirizzi IP per trovare il server e inviare i dati.

La gerarchia rende possibile distribuire il lavoro. Un computer non deve conoscere tutti i nomi del mondo: può chiedere a server DNS organizzati per livelli, partendo dai domini principali come .org, .edu o codici paese.

Gerarchia dei nomi di dominio

In un URL, il percorso individua un file dentro cartelle sul server. Allo stesso modo, il nome di dominio individua un sito dentro la gerarchia DNS. Per esempio, snap.berkeley.edu è un sottodominio di berkeley.edu, che appartiene al dominio principale .edu.

I domini principali possono indicare categorie, come .gov, oppure paesi, come .it o .mx. Le parti più a sinistra indicano sottodomini sempre più specifici.

Gerarchia degli indirizzi IP

Quando digiti un nome di dominio, il browser interroga il DNS per trovare l'indirizzo IP del server. Anche gli indirizzi IP sono gerarchici, ma si leggono in modo diverso dai nomi di dominio: le parti iniziali indicano reti più ampie, mentre le parti finali identificano dispositivi o sottoreti più specifiche.

Usare un nome di dominio o un indirizzo IP è un'astrazione: non devi conoscere tutti i passaggi, i router e i server coinvolti per raggiungere la destinazione.
