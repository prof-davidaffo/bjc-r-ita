Linguaggio di modeling: Plurali, Parte 1

Siri e altri robot sono programmati per generare linguaggio. Siri parla; alcuni robot scrivono. Tu hai sviluppato un programma, gossip, che scrive. In questo progetto, estenderai le capacità linguistiche del computer sviluppando un blocco reporter, plural, che prende un nome come input e restituisce il plurale scritto correttamente.

Fare il plurale può sembrare quasi automatico per una persona, ma non è semplice: un computer ha bisogno di un algoritmo per farlo.
Questo progetto usa blocchi già caricati dalla libreria “Words, sentences” di Snap!. Puoi caricare una libreria dal menu File di Snap! scegliendo “Libraries...”.
