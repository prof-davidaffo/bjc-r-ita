Lab 2, Pagina 2: Tipo di dato astratto (ADT) e Astrazione dei dati
  • AAP.1.D.1

    La parola "astratto" viene spesso usata in modo colloquiale per indicare qualcosa di più difficile da capire o più complesso, ma in informatica il suo significato è quasi l’opposto. Gli ADT sono cose che tu, il programmatore, crei per rendere il tuo programma più facile da leggere, da fare debug e da migliorare.

    Un tipo di dato astratto (ADT) è un tipo di dato personalizzato che è significativo per il tuo programma. Non è integrato nel linguaggio: lo sviluppi mentre programmi. È un’astrazione perché nasconde i dettagli dentro costruttore e selettori così che il programmatore che usa un quiz item debba pensare solo a domande e risposte, non agli indici della lista.
  • Il blocco è il costruttore; costruisce un esempio della struttura dati. Assegnando nomi ai pezzi della struttura, il costruttore fa in modo che ogni volta che lo usi tu costruisca la struttura nell’ordine corretto.
  • I blocchi e sono i selettori; ciascuno seleziona una parte della struttura dati.
Il costruttore e i selettori insieme implementano il tipo di dato astratto quiz item.

Lab 2, Pagina 3: Scorrere una lista
AAP-2.O.2

Scorrere una lista significa guardare ogni elemento della lista. For each è iterativo. Cioè, è ripetitivo, come for, che può anche scorrere una lista. Ma, a differenza di for, for each scorre la lista senza usare numeri di indice.

Lab 3, Pagina 1: Tipo di input, Tipo di output, Dominio e Intervallo
  • Il tipo di input (spesso chiamato dominio dai programmatori) di una funzione è il tipo di dato che accetta come input.

Lab 3, Pagina 1: Sequenziamento, Selezione e Iterazione
Selezione: AAP-2.G.1; sequenziamento, selezione, iterazione: AAP-2.A.4

Selezione significa decidere (selezionare) quale parte di un algoritmo eseguire in base al fatto che una condizione sia vera o falsa.

Ogni algoritmo può essere costruito usando sequenziamento (seguire i passi in ordine), selezione (decidere) e iterazione (ripetere).

Lab 4: Matematica con i computer

Lab 4, Pagina 2: Libreria software

Una libreria software è una raccolta di procedure che possono essere usate nei programmi.

Lab 4, Pagina 2: Interfaccia di programmazione delle applicazioni (API)
AAP-3.D.4, AAP-3.D.5

Un’interfaccia di programmazione delle applicazioni (API) documenta ciò che un programmatore deve sapere per usare una libreria: è una descrizione dello scopo di ogni procedura, dei suoi input e output (ma non dei suoi algoritmi).

Cos'è una Web API?

Un tipo comune di API è una web API in cui la libreria esiste sul computer di qualcun altro. Per esempio, la Google Maps API descrive come incorporare una mappa di Google nel tuo sito web.

Una web API è semplicemente una chiamata a una procedura su un’altra macchina. Per esempio, queste sono tre notazioni diverse per la stessa chiamata di procedura, che cerca il numero di ricerche per "BJC" negli Stati Uniti:

  • https://trends.google.com/trends/explore?q=BJC&geo=US 
  • EXPLORE (q = BJC, geo = US)
L’unica differenza è che l’URL mostra dove su Internet trovare la procedura.

Lab 5, Pagina 2: Software libero, Open source e Open access
IOC-1.F.5

Idee simili a Creative Commons sono usate per tipi particolari di materiale:

  • Software libero significa software che chiunque può copiare, usare, modificare e ridistribuire, anche commercialmente, a patto che eventuali modifiche restino sotto la stessa licenza.
    Il “a patto che” non lo rende non libero?
    La ragione di quella restrizione è impedire ad altri di trasformare una versione modificata del software in software non libero con licenze restrittive. È l’unica cosa che non puoi fare: renderlo non libero.
  • Open source è un termine più generale che significa che rendi disponibile a chiunque il codice sorgente (leggibile dagli umani) del programma. Puoi comunque limitare il modo in cui le persone possono usare il programma.
    Qual è il senso di renderlo disponibile se non si può usare?
    Una ragione è per il software di sicurezza, così che le persone possano controllare che il software non stia perdendo la tua password o altri dati e quindi possano fidarsi. (Una ragione per cui molte persone non si fidano delle macchine per il voto elettronico è che i produttori tengono il codice segreto.) Un’altra ragione per l’open source è che speri che altre persone contribuiscano a migliorare il tuo software proprietario.
  • Open access indica che gli articoli di ricerca accademica sono disponibili per il download gratuito, anziché richiedere il permesso dell’editore della rivista.
