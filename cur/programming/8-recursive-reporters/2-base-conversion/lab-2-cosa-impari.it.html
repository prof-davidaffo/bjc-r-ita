Unità 8, Laboratorio 2: Cosa impari

Divisione e resto

Per convertire un intero non negativo in base 2, il resto della divisione per 2 dà la cifra meno significativa; il quoziente contiene il problema rimanente. Per 13: 13 = 2×6 + 1, 6 = 2×3 + 0, 3 = 2×1 + 1; leggendo le cifre dal risultato più significativo si ottiene 1101₂.

Ricorsione e ordine delle cifre

La chiamata ricorsiva converte il quoziente; il resto viene aggiunto alla sua destra. Il caso base gestisce i numeri più piccoli della base, incluso zero secondo la rappresentazione scelta. L’ordine della combinazione determina l’ordine delle cifre.

Rivedi l’attività.

Generalizzare la base

Sostituire 2 con una base b permette di usare la stessa relazione n = b×quoziente + resto. Il resto individua una cifra tra 0 e b−1; la conversione inversa interpreta le cifre in base ai loro valori posizionali.
