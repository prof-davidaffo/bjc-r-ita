Numeri pari e keep

In questa pagina costruirai altre due funzioni di ordine superiore che hai studiato nel corso: keep e combine.

Vogliamo un blocco che prende in input una lista di numeri e restituisce una lista contenente solo i numeri pari dell'input.

Sai gia' scrivere questo blocco usando la funzione di ordine superiore keep, ma ecco com'è usando la ricorsione:

Qui ci sono tre casi possibili da considerare, non solo il solito caso base e caso ricorsivo. C'è ancora un caso base: una lista di input vuota, per cui restituiamo una lista vuota. Ma ci sono due casi ricorsivi, a seconda che il primo elemento della lista sia pari oppure no. Se non siamo nel caso base, un primo elemento esiste per forza. I blocchi verdi Operators calcolano il resto della divisione del primo numero per 2 e controllano se è 0: in quel caso il numero è pari.

Se il primo numero è pari, vogliamo includerlo nel risultato. Quindi restituiamo quel numero in front of la chiamata ricorsiva sul resto dei numeri. Se il primo numero non è pari, non vogliamo includerlo, quindi restituiamo semplicemente il valore prodotto dalla chiamata ricorsiva.

Come plurals, il codice di evens è un esempio di pattern. Qui non c'è nulla di speciale sui numeri pari: lo stesso pattern può creare una lista di numeri dispari, numeri che finiscono per 7 o nomi che iniziano con Z.

Svolgi gli esercizi seguenti usando la ricorsione, non funzioni di ordine superiore.

  1. Prova a modificare il codice di evens.
    Scrivi un blocco ends-e che prende in input una lista di parole e restituisce una lista delle parole il cui ultimo carattere è e.
  2. Scrivi un blocco numbers che prende in input una lista mista di parole e numeri e restituisce una lista contenente solo i numeri dell'input.
  3. Generalizza il pattern per creare un blocco keep.
  4. Scrivi il blocco combine. Nota: il caso base sarà una lista con un solo elemento, non una lista vuota.
