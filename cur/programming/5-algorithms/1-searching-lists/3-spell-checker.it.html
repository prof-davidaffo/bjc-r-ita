In questa pagina, confronti linear search e binary search.

Se devi verificare se una parola esiste in un dizionario molto grande, puoi usare strategie diverse. La scelta dell'algoritmo fa molta differenza quando i dati sono tanti.

  1. Apri il progetto con il dizionario: carica progetto.
  2. Prova a cercare parole corrette e parole sbagliate con linear search.
  3. Implementa o completa binary search e confronta i tempi.
  4. Spiega: perché binary search funziona bene solo su liste ordinate?
: Linear Search

Controlla gli elementi uno alla volta fino a trovare il valore (o fino alla fine della lista).

: Binary Search

Con lista ordinata: confronta col valore centrale e scarta ogni volta meta della lista.

  1. Individua due situazioni in cui useresti per forza linear search.
  2. Individua due situazioni in cui conviene preparare i dati ordinati e poi usare binary search.
