Importare e accedere ai dati

In questa pagina, impari a importare tabelle e usare colonne/record in modo sistematico.

Un file CSV rappresenta spesso una tabella: prima riga come header, righe successive come record. Da li puoi costruire query e blocchi riutilizzabili.

  1. Importa un dataset in formato CSV.
  2. Individua: header, un record, una colonna e un campo specifico.
  3. Crea un blocco che restituisce una colonna dato il suo nome.
  4. Formula una domanda reale sul dataset e costruisci il codice per rispondere.
: Record

Una riga della tabella (un elemento osservato).

: Campo

Un valore specifico dentro un record.

: Colonna

Tutti i valori dello stesso attributo.
