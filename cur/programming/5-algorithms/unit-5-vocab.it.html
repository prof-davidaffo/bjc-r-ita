Vocabolario Unita 5

: Algoritmo

Procedura precisa, finita e ripetibile per risolvere un problema.

: Istanza di problema

Un caso specifico di un problema generale.

: Linear Search

Ricerca sequenziale elemento per elemento.

: Binary Search

Ricerca su lista ordinata che dimezza ogni volta lo spazio di ricerca.

: Efficienza

Quanto costa un algoritmo in termini di tempo e risorse.

: Tempo costante / lineare / quadratico

Categorie che descrivono come cresce il costo al crescere dell'input.

: Tempo polinomiale

Crescita considerata in genere ragionevole per input grandi.

: Tempo esponenziale

Crescita molto rapida, spesso impraticabile.

: Euristica (heuristic)

Strategia veloce che produce una soluzione approssimata ma utile.

: Problema decisionale

Problema con risposta vero/falso.

: Problema di ottimizzazione

Problema in cui si cerca la soluzione migliore tra molte possibili.

: Problema decidibile / indecidibile

Decidibile: esiste un algoritmo generale corretto per tutti gli input. Indecidibile: non esiste.

: Computazione parallela

Esecuzione contemporanea di parti di un compito.

: Computazione distribuita

Esecuzione di un compito su piu macchine in rete.

: Dati (data)

Valori raccolti da sorgenti diverse.

: Informazione (information)

Significato utile estratto dai dati.

: Correlazione

Relazione statistica tra variabili; non implica causalita.

: Metadati (metadata)

Informazioni sui dati (autore, data, posizione, formato, ecc.).

: Bias

Distorsione che puo portare a conclusioni fuorvianti.

: Pulizia dei dati (data cleaning)

Processo di correzione, uniformazione e validazione dei dati.
