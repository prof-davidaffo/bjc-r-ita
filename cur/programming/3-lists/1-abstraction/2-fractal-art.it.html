Arte frattale

In questo progetto, anniderai blocchi repeat dentro altri blocchi repeat per generare immagini complesse.

  1. "U3L1-FractalArt"
  2. Costruisci uno script che disegna un triangolo rosso, duplicalo due volte, modifica una copia per disegnare un triangolo blu grande la metà del rosso, e modifica l'altra copia per disegnarne uno verde grande la metà del blu.
    • Per duplicare uno script, fai clic destro (o control-clic) sul primo blocco dello script (in questo caso il blocco repeat) e scegli "duplica".
    • Poi cambia gli input.
    Clicca per un video.
  3. Prova ciascuno script da solo per essere sicuro di cosa fa. Poi cancella il palco.
  4. Prevedi cosa succederà quando inserisci l'intero script del triangolo blu tra i blocchi move e turn del codice per il triangolo rosso:
  5. Poi costruiscilo per vedere cosa fa.
  6. Quante volte viene eseguita l'istruzione move 50 steps e perché?
  7. Usando gli script che hai, trova un modo per creare questa immagine. Usa Visible Stepping per aiutarti a risolvere eventuali bug.
    8. Clicca per un video promemoria su Visible Stepping.
  1. Se vuoi, incorpora un altro triangolo, grande la metà dell'ultimo, nello stesso modo.
  2. Esamina questo codice senza eseguirlo:
    1. Prevedi quante forme blu disegnerà.
    2. Prova a schizzare cosa produrrà.
    3. Se un'altra copia dello script di base fosse incorporata dentro il blu, quante copie di quella forma verrebbero disegnate?
