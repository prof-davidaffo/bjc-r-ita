Ecco la parte più difficile: per far funzionare tutto correttamente, un nome (come definito dal TDA name) deve sapere se è un nome con nome-prima come Jasmine Anderson o cognome-prima come Sun Yat-Sen. Ridefinisci il tuo TDA Name per renderlo una lista di tre elementi. Il primo sarà il testo 'given-first' o 'family-first'. Questo primo elemento è detto type tag. Il secondo elemento sarà il nome (o i nomi) e il terzo il cognome (o i cognomi).
    Hai usato i type tag da sempre senza saperlo. Molti linguaggi di programmazione, incluso Snap!, associano type tag a ogni valore, dicendo "sono una lista" o "sono un numero" e così via. L'utente (cioè tu) non vede i type tag, a meno che tu non fornisca un input errato a un blocco primitivo e tu veda un messaggio come "Expected list but got text".
