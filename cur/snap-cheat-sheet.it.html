Scheda di riferimento Snap!

Questa guida mostra come collegare le procedure del linguaggio usato nell'esame AP ai blocchi di Snap!.

Assegnazione, visualizzazione e input

Nell'esame AP
In Snap!
Note
a ← expression
In Snap! devi creare una variabile prima di assegnarle un valore. Puoi creare variabili globali dalla palette Variabili o variabili locali con variabili di script.
DISPLAY (expression)
In Snap! puoi mostrare dati con fumetti, pensieri o testo sullo stage usando blocchi come say, think e write.
INPUT ()
In Snap! l'input dell'utente si ottiene con ask; la risposta e' disponibile nel blocco answer.

In Snap!
Note
a + b

a - b

a * b

Puoi inserire numeri, variabili o altre espressioni numeriche negli slot.
a MOD b
Il blocco mod restituisce il resto della divisione.
RANDOM (a, b)
Sceglie un valore casuale nell'intervallo indicato.

Selezione e iterazione

Nell'esame AP
In Snap!
Note
IF (condition)
{
    <statements>
}
Esegue i blocchi interni solo se la condizione e' vera.
IF (condition)
{
    <statements>
}
ELSE
{
    <statements>
}
Sceglie tra due sequenze di blocchi.
REPEAT n TIMES
{
    <statements>
}
Ripete una sequenza un numero fissato di volte.
REPEAT UNTIL (condition)
{
    <statements>
}
Ripete finche' la condizione diventa vera.

Operazioni sulle liste

Nell'esame AP
In Snap!
Note
list[i]
Restituisce l'elemento nella posizione i.
list[i] ← value
Sostituisce un elemento della lista.
FOR EACH item IN list
{
    <statements>
}
Esegue la stessa sequenza per ogni elemento della lista.
INSERT (list, i, value)

APPEND (list, value)

REMOVE (list, i)

LENGTH (list)
I blocchi Snap! hanno spesso gli stessi effetti ma un ordine degli input leggermente diverso.

Procedure

Nell'esame AP
In Snap!
Note
PROCEDURE name (parameters)
{
    <instructions>
}
Una procedura che esegue azioni corrisponde a un blocco comando.
PROCEDURE name (parameters)
{
    <instructions>
    RETURN expression
}
Una procedura che restituisce un valore corrisponde a un reporter con un blocco report.

Robot

Questi blocchi non esistono direttamente in Snap!. Il linguaggio AP li usa per un robot che si muove su una griglia; in Snap! puoi simularli con movimento dello sprite, rotazioni e sensori.

Nell'esame AP
Come ricrearlo in Snap!
MOVE_FORWARD ()
Usa con un numero di passi uguale al lato di una casella della griglia. Nell'esame AP non puoi dare input a MOVE_FORWARD(), quindi per avanzare di piu' caselle devi chiamarlo piu' volte.
ROTATE_LEFT ()

ROTATE_RIGHT ()
Usa o con 90 gradi. Nell'esame AP queste procedure ruotano sempre esattamente di 90 gradi.
